### 架构要点

- **三层分离**：`core/` 纯逻辑（不碰 DOM）↔ `ui/` 渲染交互 ↔ `data/` 静态数据。引擎通过 `ui-bridge.js` 与 `ai-bridge.js` 两个「桥」对象向外暴露钩子，运行时由 `render.js` / `bot.js` / `api-bot.js` 注入具体实现，避免循环依赖。
- **无构建、无依赖**：原生 ES Module，浏览器直接加载即可；头像与卡牌图案全部用程序化 SVG 生成，零外部图片/字体。
- **可选 LLM 增强**：默认全本地 AI（离线可玩）；开启「用 API AI 接管座位」并配置端点后，部分座位改由 LLM 决策（需联网）。

# 第一部分 · 认识「三国杀」

## 1. 它是什么

三国杀是一款基于中国三国历史背景设计的**多人卡牌桌游（Card Game）**，玩家扮演武将，通过「摸牌—出牌—弃牌」的回合制流程，利用卡牌与武将技能相互攻防，最终达成身份/阵营的胜利条件。它融合了**身份推理、手牌管理、数值对抗**三大要素，是中文卡牌桌游的代表作。

本游戏采用经典的 **标准身份局** 规则，并扩展了武将与卡牌规模。

## 2. 核心概念

| 概念 | 说明 |
|------|------|
| **体力（HP）** | 每个武将的"血量"，受伤害减少，用【桃】回复；降到 0 进入濒死，需他人救活否则阵亡 |
| **手牌** | 你当前可使用的牌，回合结束需弃到「手牌上限」 |
| **手牌上限** | 默认 = 当前体力值（部分技能/装备会调整） |
| **距离** | 与另一角色的座位间隔；影响你能不能打到对方（有进攻马/技能可缩短） |
| **攻击范围** | 默认 1；装备武器后增大，决定你能用【杀】打多远的目标 |
| **锦囊牌** | 一次性使用的功能牌（过河拆桥、万箭齐发、五谷丰登等） |
| **装备牌** | 武器 / 防具 / 坐骑，穿上后持续生效 |
| **判定** | 从牌堆顶翻一张牌决定某效果成败（延时锦囊、洛神、观星相关等） |
| **拼点** | 双方各出一张手牌比点数，K>Q>J>10>…>2>A，同点算没赢，拼完都弃 |

## 3. 卡牌体系（共 126 张）

| 类别 | 数量 | 构成 |
|------|------|------|
| **基本牌** | 58 | 杀 ×30 · 闪 ×16 · 桃 ×9 · 酒 ×3 |
| **锦囊牌** | 42 | 延时 ×6（乐不思蜀/闪电/兵粮寸断）· 普通 ×36 |
| **装备牌** | 26 | 武器 ×13 · 防具 ×5 · 坐骑 ×8 |

### 基本牌
- **【杀】**：对距离内一名角色造成 1 点伤害；每回合限 1 张（部分武将/武器可突破）。
- **【闪】**：抵消一张【杀】。
- **【桃】**：回复 1 点体力；自己回合外只能用于濒死角色。
- **【酒】**：本回合下一张【杀】伤害 +1；自己濒死时可当【桃】用。

### 锦囊牌
- **延时锦囊**（放在目标头顶，判定阶段结算）：
  - 【乐不思蜀】：判定不为 ♥，跳过出牌阶段。
  - 【闪电】：判定为 ♠2~9，受 3 点雷电伤害，否则转下家。
  - 【兵粮寸断】：判定不为 ♣，跳过摸牌阶段。
- **普通锦囊**：无中生有（摸 2）、过河拆桥（弃对方一张牌）、顺手牵羊（拿 1 距离内对方一张牌）、决斗、南蛮入侵（众人出杀）、万箭齐发（众人出闪）、桃园结义（全体回复 1）、五谷丰登（亮牌各选一张）、无懈可击（抵消锦囊）、借刀杀人、火攻、铁索连环、知己知彼。

### 装备牌
- **武器**（13 件，带攻击范围与特效）：诸葛连弩、雌雄双股剑、青釭剑、青龙偃月刀、丈八蛇矛、贯石斧、方天画戟、麒麟弓、干将莫邪、开山大斧、落日弓等。
- **防具**（5 件）：八卦阵、仁王盾（挡黑色杀）、藤甲（挡普通杀/南蛮/万箭，但火焰 +1）、明光铠。
- **坐骑**（8 件）：赤兔、的卢、绝影、爪黄飞电、白马（无视距离）、紫骍、惊帆、快航。

## 4. 武将与技能

每个武将有 2~4 个技能，分三类：
- **主动技（active）**：出牌阶段主动发动（制衡、苦肉、仁德、青囊、反间、义绝、天义、辕门、离间、双雄等）。
- **触发技（trigger）**：在特定事件时触发（受伤害、出牌后、回合开始/结束等）。
- **锁定技（passive）**：永久生效、无法放弃（咆哮、龙胆、武圣、空城、马术、神射等）。

此外**主公技**只有"主公"身份才能发动（魏王、救援、黄天、暴虐、激将等）。

# 第二部分 · 重制版（本项目）

## 1. 项目定位

这是一个**纯前端、单机**的网页版三国杀。特点：

- **无构建、无依赖**：原生 ES Module，浏览器打开 `index.html` 即玩。
- **规模**：32 武将 · 126 卡牌 · 4~8 人 · 3 种模式。
- **可选 LLM 增强**：默认全本地 AI（离线可玩）；勾选「用 API AI 接管座位」并配置端点后，可用大模型驱动部分 AI 座位。

## 2. 三种游戏模式

| 模式 | 人数 | 说明 |
|------|------|------|
| **身份局** | 4~8 | 随机身份（主公/忠臣/反贼/内奸），主公亮明。推理 + 对抗，最后达成胜利条件者胜 |
| **2v2** | 固定 4 | 分两队（红 A / 蓝 B）交错就座，击杀敌方全体即胜 |
| **3v3** | 固定 6 | 两队各 3 人，规模适中、讲究配合 |

## 4. 本版特色机制

- **属性伤害 + 铁索连环**：普通伤害（杀/决斗/南蛮/万箭）、火焰伤害（火攻/藤甲传导）、雷电伤害（闪电/雷击）。被【铁索连环】的角色受到属性伤害时，其他连环角色同量传导，结算后解除。
- **藤甲克制**：装藤甲时普通杀/南蛮/万箭对其无效，但受火焰伤害 +1。
- **装备特效联动**：武器（青龙偃月刀追加杀、贯石斧弃牌强杀、方天画戟额外目标…）、防具（仁王盾挡黑杀、八卦阵判定代闪…）、坐骑（白马无视距离、惊帆攻防合一…）互相影响伤害与距离计算。
- **武将技能深度联动**：技能可在回合各阶段、伤害前后、判定时触发，与装备/卡牌形成组合打法。
- **左慈"化身"**：开局随机获得两名其他武将的首技能，增加每局变数。

## 5. 胜负条件

**身份局**：
- 主公：消灭所有反贼和内奸。
- 忠臣：保护主公，与主公共同胜利。
- 反贼：杀死主公。
- 内奸：杀光除主公外所有人，最后独自杀死主公。

**团队模式**：本队全灭则败；击杀对方全体成员即胜。

**濒死与救活**：体力 ≤ 0 进入濒死，按座位顺序（濒死者优先自救）可对其使用【桃】，每回复 1 点需 1 张桃；无人救活则阵亡。

## 6. 回合流程（每名玩家）

1. **准备阶段**：洛神、观星等技能触发。
2. **判定阶段**：结算头顶延时锦囊（乐/闪电/兵粮）。
3. **摸牌阶段**：摸 2 张（英姿 3 张；兵粮寸断跳过；神速可跳过）。
4. **出牌阶段**：使用手牌（杀每回合默认 1 张，咆哮/连弩可突破）。
5. **弃牌阶段**：弃到「手牌上限」（克己可跳过）。
6. **结束阶段**：闭月、崩坏等触发。

# 第三部分 · 玩法与使用方法

## 1. 网页版运行（最简单）

1. 把项目目录拷到任意位置。
2. 用现代浏览器（Chrome / Edge / Safari / Firefox）直接打开 `index.html`。
3. 在「开始游戏」页填写名字、选模式/人数/难度，点 **开始一局**，选武将、看身份，开始对局。

> 无需安装、无需联网（除非启用 API AI）。注意：ES Module 在部分浏览器下需通过 `http(s)://` 或 `file://` 正确加载；若直接双击打开遇到模块加载问题，可启动一个本地静态服务器：
> ```bash
> # 任选其一
> python3 -m http.server 8000     # 然后访问 http://localhost:8000
> # 或
> npx serve .
> ```

## 2. 界面操作速查

| 位置 | 作用 |
|------|------|
| 顶部「战报」 | 打开/关闭滚动日志面板 |
| 顶部「规则」 | 查看规则速览 |
| 顶部「退出」 | 退出本局回大厅 |
| 顶部「全屏」 | 切换全屏 |
| 中央 | 牌堆 / 使用区 / 弃牌堆 |
| 各座位头像 | 点击查看该武将技能详情与距离 |
| 底部手牌 | 点击选中 → 出牌阶段点「确定」打出；响应阶段按提示点「出闪/出桃/出杀」 |
| 底部「结束出牌」 | 出牌阶段手动结束本回合出牌 |

## 3. 图鉴与规则

- 首页的「武将图鉴」「卡牌图鉴」「规则手册」四个标签页可随时查阅 32 武将、126 卡牌与完整规则（支持按势力筛选、关键词搜索）。

## 4. 可选：用 LLM API 接管 AI 座位

默认所有非玩家座位由本地脚本 AI 决策（离线可玩）。若想用大模型驱动：

1. 首页勾选「**用 API AI 接管座位**」，点「**配置 API / 扫码**」。
2. 三选一：
   - **扫二维码**：用另一台设备生成配置二维码，本机摄像头扫入；
   - **手动粘贴 JSON**：参考 `examples/api-config-example.json`（DashScope / Ollama 各有示例）；
   - 模板已内置，替换 `apiKey` / `endpoint` / `model` 即可。
3. 保存后，被接管的座位会改由 LLM 出招（走 CORS 代理，默认 `corsproxy.io`；自有端点开 CORS 可设为 `""`）。

配置 JSON 关键字段（`schema: "sgs-ai-endpoint/v1"`）：
```json
{
  "provider": "openai-compat",
  "endpoint": "https://.../chat/completions",
  "apiKey": "sk-...",
  "model": "gpt-4o-mini",
  "temperature": 0.6,
  "seat": { "mode": "replace-one", "index": -1, "fallback": "local-bot" }
}
```
`seat.mode`：`replace-one`（单座位）/ `replace-all`（全部 AI）/ `assist`（辅助我）。

## 5. 开发者使用（改代码 / 扩展）

- **加卡牌**：在 `js/data/cards.js` 的 `CARD_DEFS` 里定义，并用 `push(defId, suit, rank, n)` 加入 126 张分布；结算逻辑加到 `js/core/cards-resolver.js` 的 `HANDLERS`。
- **加武将**：在 `js/data/generals.js` 的 `GENERALS` 数组加条目（`id/name/fac/hp/gender/skills`），技能挂到 `js/core/skills.js` 对应事件钩子；头像由 `js/ui/portraits.js` 程序化生成，无需贴图。
- **跑自测**：项目纯 ESM，可用 Node 起一个最小 DOM 桩后 `import('./js/main.js')` 驱动 `Turn`/`CardResolver` 做回归。

## 6. 打包成 Android APK（可选）

本项目是 Web 应用，可包一层 **Android WebView 壳** 出 APK：

1. 用 `esbuild` 把 `js/main.js` 打成单文件 IIFE bundle（WebView 用 `file://` 加载 ESM 会因同源策略失败，必须单文件）：
   ```bash
   esbuild js/main.js --bundle --format=iife --minify --target=es2019 --outfile=www/app.bundle.js
   # index.html 里 <script type="module" src="./js/main.js"> 换成 <script src="./app.bundle.js">
   ```
2. 写一个 `MainActivity`（WebView + 开启 JS/localStorage + 从 `file:///android_asset/www/index.html` 加载 + 锁定横屏全屏），配 `AndroidManifest.xml`。
3. 用 Android build-tools 原生构建链：
   ```
   javac(编译) → d8(转 dex) → aapt2(链接资源) → 合并 dex+assets → zipalign(对齐) → apksigner(签名)
   ```
4. 产物 `三国杀.apk` 直接安装即可（需允许未知来源；debug 证书适合自用，上架需换正式 keystore）。
